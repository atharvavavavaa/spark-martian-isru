# SPARK: Martian Closed-Loop ISRU System 

> Developed for the **NASA International Space Apps Challenge 2025**.

A conceptual systems engineering framework and computational pipeline modelling closed-loop Martian In-Situ Resource Utilisation (ISRU) for atmospheric CO₂ extraction, processing, and oxygen generation.

# System Architecture
SPARK integrates three thermodynamic and chemical conversion sub-stages designed to run on autonomous operational loops:
- **Atmospheric Acquisition & Compression:** Cryogenic/mechanical sorption capture targeting high-density Martian ambient CO₂ (~95%).
- **Sabatier & Electrolysis Integration:** Solid Oxide Electrolysis (SOEC) coupled with methanation loops to maximise per-kilowatt $O_2$ and propellant yield.
- **Closed-Loop Mass Flow Validation:** Stoichiometric tracking across life-support and fuel-generation pipelines to minimise parasitic mass loss.
